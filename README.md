# AFTAB MODZ — Android Project

This is Phase 1 of the Android conversion of `tool.py`.

- Premium red/black/gold GUI
- User portrait included as `assets/aftab.jpg`
- Android portrait layout
- Six tool screens/buttons matching the existing tool menu
- Original `tool.py` copied into the project for the next integration phase

## Build

The included GitHub Actions workflow builds a debug APK with Buildozer.
After the UI APK works, the next phase connects the existing PAK engine from `tool.py` and its Python dependencies.
